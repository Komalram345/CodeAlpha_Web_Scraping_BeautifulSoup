# Web Scraping using BeautifulSoup

## Author
Komal Ram

## Project Overview
This project demonstrates web scraping using Python. Data is extracted from a public website using BeautifulSoup and Requests. The scraped data is cleaned, analyzed, visualized, and exported as a CSV file.

## Features
- Web Scraping using BeautifulSoup
- HTML Parsing
- Data Cleaning
- Data Analysis
- Data Visualization
- CSV Export

## Technologies Used
- Python
- BeautifulSoup
- Requests
- Pandas
- Matplotlib

## Dataset
The dataset was created by scraping data from:
https://books.toscrape.com/

## Results
- Successfully extracted Book Name, Price, and Rating.
- Cleaned the data.
- Created a custom dataset.
- Generated visualizations.
- Performed exploratory data analysis.

This project demonstrates practical knowledge of web scraping, HTML parsing, data cleaning, and data visualization using Python.
